# Mon Voyage 🇫🇷 — French vocabulary trainer

Open `index.html` in a browser (no build, no server needed). Progress is saved in your browser (localStorage).

- **Learn** – flip-cards (French + image first, you flip to English + example sentence); pronunciation auto-plays; rate each card Needs practice / Still learning / Memorized.
- **Test** – English shown, you type the French.
- **Practice** – fill in the blank, meaning quiz, listen-and-pick.
- **Read** – short texts using the level's words (tap any word to hear it).
- **My Words** – add your own words (single or bulk), change statuses, delete.
- Levels A1–B2 + your own list; filter by status to target weak words.
- Audio uses your device's French voices (🔊 → pick a Neural/Premium/Enhanced/Google voice for best quality).
